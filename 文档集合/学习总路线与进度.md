## 当前阶段：IMMPF

当前只学习 IMMPF 的入门层，不进入 DIMMPF 可微训练和 ELBO。

IMMPF 第一轮目标：

```text
理解 PF 如何扩展成多个模型/regime 的粒子滤波。
```

重点代码：

```text
Net.py
    class IMMPF
        M_0_proposal(k, ...)
        M_t_proposal(k, ...)
        log_f_t(k, ...)
        get_regime_probs(...)

simulationRS.py
    class IMM_Particle_Filter
        initialise()
        advance_one()
```

第一轮验收标准：

- 能解释为什么 IMMPF 的方法多了参数 `k`。
- 能解释 `get_regime_probs()` 返回什么。
- 能说明 `simulationRS.advance_one()` 为什么要对每个模型 `k` 循环。
- 能说清 PF 与 IMMPF 的核心区别。

## 已掌握

PF 阶段已经掌握：

- 粒子表示隐藏状态的一种可能性。
- 多个粒子用于近似后验分布，而不是只维护一个点估计。
- `M_0_proposal()` 生成初始粒子。
- `M_t_proposal()` 将粒子从 `t-1` 推进到 `t`。
- `log_f_t()` 用观测 `y_t` 给粒子打分。
- `a`、`b` 是不同 regime/model 的动态与观测参数。
- `log_R_t()` 用于修正提议分布和目标动态分布之间的差异。

## 需复习

进入 IMMPF 前，PF 阶段需要持续记住：

```text
粒子滤波用很多粒子近似后验分布 p(x_t | y_0:t)。
Bootstrap PF 的提议分布等于状态转移先验，不等于后验。
```

张量形状需要持续检查：

```text
x_t_1.shape = (B, N, D)
x_t_1[:, :, 0]  -> (B, N)，位置
x_t_1[:, :, 1:] -> (B, N, D-1)，模型/模式信息
```
