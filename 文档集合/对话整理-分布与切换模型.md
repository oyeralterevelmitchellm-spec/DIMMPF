# 对话整理：正态分布与切换模型

## 1. PyTorch 正态分布对象的创建

**代码位置**：`Net.py:2346`

```python
self.x_dist = pt.distributions.Normal(pt.zeros(1), sqrt(var_s))
```

### 含义分解

| 部分 | 含义 |
|------|------|
| `pt.distributions.Normal` | PyTorch 的正态分布类 |
| `pt.zeros(1)` | 均值 $\mu = 0$（一维张量） |
| `sqrt(var_s)` | 标准差 $\sigma = \sqrt{var_s}$（由方差开方得到） |
| `self.x_dist` | 将该分布保存为实例属性 |

### 作用

该代码创建了一个**均值为 0、标准差为 $\sqrt{var_s}$ 的正态分布对象**，通常用于定义状态转移噪声或过程噪声的分布。在粒子滤波中，它作为提议分布（proposal distribution）或状态演化模型的一部分，用于从中采样粒子噪声。

## 2. 各滤波算法使用的切换模型（switching_dyn）汇总

### 2.1 预定义解析切换模型 vs 神经网络学习切换模型

| 类别 | 切换模型类 | 特点 |
|------|-----------|------|
| **预定义解析模型** | `Markov_Switching` | 基于马尔可夫转移概率矩阵 |
| | `Polya_Switching` | 基于波利亚 urn 模型（计数器机制） |
| | `Erlang_Switching` | 基于爱尔朗分布的切换 |
| **神经网络学习模型** | `NN_Switching` | 由 RNN 端到端学习模式切换策略 |

### 2.2 各算法实际使用的切换模型

#### PF（Particle Filter）

- **用途**：主要用于 `create_data()` 生成模拟数据。
- **切换模型**：由 `args.experiment` 参数决定，**不是固定的**。
  - `"Markov"` → `Markov_Switching(8, 0.8, 0.15, "Boot", device)`
  - `"Polya"` → `Polya_Switching(8, "Boot", device)`
  - 其他 → `Erlang_Switching(8, "Boot", device)`

> 注：`Net.py:1750` 中的 `pf = PF(..., switching_dyn=markov_switch)` 仅为类文档中的示例代码，不代表实际运行配置。

#### IMMPF（Interacting Multiple Model Particle Filter）

- **用途**：传统 IMM-PF 算法，不经过端到端训练。
- **切换模型**：同样由 `args.experiment` 参数决定，支持三种预定义模型：
  - `"Markov"` → `Markov_Switching`
  - `"Polya"` → `Polya_Switching`
  - 其他 → `Erlang_Switching`

#### RLPF（Recurrent Learning Particle Filter）

- **用途**：DIMMPF 的简化版，**只学习切换动力学**，不学习状态转移。
- **切换模型**：固定使用 `NN_Switching`
  ```python
  NN_Switching(8, 8, "Uni", args.device, 0)
  ```

#### DIMMPF（Deep IMM Particle Filter）

- **用途**：端到端深度学习方法，**同时学习切换和状态转移**。
- **切换模型**：固定使用 `NN_Switching`
  ```python
  NN_Switching(8, 8, "Uni", args.device, 0.1)
  ```

### 2.3 总结对照表

| 算法 | 切换模型 | 是否可学习 | 备注 |
|------|---------|-----------|------|
| **PF** | Markov / Polya / Erlang | 否 | 用于数据生成，按实验配置切换 |
| **IMMPF** | Markov / Polya / Erlang | 否 | 传统算法，按实验配置切换 |
| **RLPF** | `NN_Switching` | 是 | 仅学习切换策略 |
| **DIMMPF** | `NN_Switching` | 是 | 同时学习切换与状态转移 |

### 2.4 NN_Switching 的关键差异

- **RLPF** 中 `NN_Switching` 的最后一个参数为 `0`
- **DIMMPF** 中 `NN_Switching` 的最后一个参数为 `0.1`（软化参数）

该参数差异反映了两者在切换策略学习上的细微不同，但核心结构一致：均为基于循环神经网络（RNN）的可学习切换模型。
